📊 Techno Sales Dashboard (Power BI Project)

📌 Project Overview

    This project is a Power BI Sales Dashboard created to analyze and visualize sales performance of a technology products company.
    The dashboard helps understand sales trends, costs, quantity sold, brand performance, and regional sales in a clear and interactive way.

🎯 Objective

    The main objective of this project is to:

    Analyze overall sales performance

    Track total sales, cost, quantity, and transactions

    Compare sales by category, brand, state, and supervisor
  
    Build an interactive and visually appealing dashboard using Power BI

🛠 Tools & Technologies Used

    Power BI Desktop

    Microsoft Excel (Data Source)

    Git & GitHub (Version Control)

📂 Project Files

    Project_1.pbix → Power BI dashboard file

    Complete_Techno_Sales_Data.xlsx → Raw sales dataset

    README.md → Project documentation

📊 Dashboard Features

    Total Sales, Total Cost, Quantity & Transactions KPIs

    Sales by Product Category

    Sales by Brand (Pie Chart)

    Sales by State (Map Visualization)
  
    Supervisor-based filtering using slicer

    Interactive visuals with filters and drill options

📈 Key Insights

    Identifies top-performing product categories and brands
 
    Shows regional sales distribution across states

    Helps compare supervisor-wise sales performance

    Provides a quick overview of business performance using KPIs

🚀 How to Use This Project

    Download or clone the repository

    Open Project_1.pbix using Power BI Desktop

    Make sure the Excel file is in the same folder (if required)

    Interact with slicers and visuals to explore insights
